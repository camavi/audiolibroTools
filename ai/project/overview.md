# Overview Prodotto

Audiobook Tool deve diventare una piattaforma moderna per autori, editori e team editoriali che vogliono:

- creare o importare libri;
- modificare testi con un editor professionale;
- correggere e migliorare testi con AI;
- tradurre libri in piu' lingue;
- confrontare originale, revisioni e traduzioni;
- generare audiolibri con voci, toni, personaggi e pause;
- aggiungere musica, effetti sonori e timeline;
- creare copertine e asset;
- esportare o pubblicare contenuti audio/testo;
- gestire progetti, costi, job, stati e notifiche.

## Regole di Progetto

- Backend: PHP Laravel.
- Frontend pubblico/editor: Node per tooling, CSS nativo, JavaScript nativo.
- Dashboard utente loggato: usare CMSwift.
- Sito multilingua fin dall'inizio.
- Palette globale: usare `public/assets/css/palette.css`, derivata da `/Users/cmalleux/Sites/audiolibroTools_old/palette.css`.
- Non creare stili isolati pagina per pagina se possono diventare token, componenti o utility globali.
- Il vecchio progetto resta riferimento funzionale in `/Users/cmalleux/Sites/audiolibroTools_old`.
- Il documento principale di riferimento e' `/Users/cmalleux/Sites/audiolibroTools_old/info.md`.
